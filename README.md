# Квиз

Комната для опроса на мероприятии. Организатор собирает вопросы, участники заходят по коду и отвечают, пока вопрос на экране.

Стек: Go, WebSocket, Vue.

```bash
go run ./cmd/quiz
```

Страница: http://127.0.0.1:8093/

Кабинеты пишутся в `data/quiz-store.json`. Схема таблиц: `internal/quiz/schema.sql`.

Живой экземпляр: http://132.243.194.181:8081/quiz/

Макет: `static/quiz/maket.html`

Записка для платформы: `sdacha/zapiska.pdf`
