# Квиз

Веб-приложение для проведения квиза в одной комнате: организатор создаёт раунд, участники входят по коду, ответы и табло обновляются в реальном времени.

## Стек

- Go 1.25
- WebSocket (`github.com/gorilla/websocket`)
- Клиент на Vue (локальный `static/quiz/vue.global.prod.js`)
- Хранилище — JSON-файл `data/quiz-store.json`

## Запуск

```bash
go run ./cmd/quiz
```

По умолчанию сервер слушает `127.0.0.1:8093`, страница квиза — `http://127.0.0.1:8093/`.

Переменные окружения:

- `HTTP_ADDR` — адрес сервера (по умолчанию `127.0.0.1:8093`)
- `STATIC_DIR` — каталог статики (по умолчанию `static/quiz`)
- `DATA_FILE` — путь к JSON-хранилищу (по умолчанию `data/quiz-store.json`)

Внешние сервисы для локального запуска не нужны.

## Проверка

```bash
go test ./...
```

Быстрые проверки сервера:

- `GET /ping` → `pong`
- `GET /health` → `{"ok":true}`

## API и каналы

HTTP (`/api/`):

- `POST /api/register`
- `POST /api/login`
- `GET /api/me`
- `GET /api/cabinet`
- `POST /api/quizzes`

WebSocket:

- `GET /ws` — подключение клиента (организатор / участник / экран)

## Что реализовано

- Создание квиза (1–20 вопросов, 2–4 варианта, одиночный или множественный ответ)
- Запуск комнаты с 4-символьным кодом
- Вход участника по коду (с кабинетом или по имени без регистрации)
- Режим экрана зала (`#watch/<код>`)
- Таймер вопроса (0/10/15/20/30/45/60 секунд)
- Очки за правильный ответ с бонусом за скорость
- Табло, победитель, сброс раунда
- Кабинет: сохранённые квизы, история проведённых и сыгранных игр
- Демо-режим без аккаунта (preview)

## Структура

- `cmd/quiz/main.go` — точка входа
- `internal/quiz/engine.go` — логика игры и подсчёта очков
- `internal/quiz/http.go` — HTTP/WebSocket-хендлер и маршрутизация
- `internal/quiz/api.go` — JSON API кабинета
- `internal/quiz/store.go` — файловое хранилище пользователей/квизов/истории
- `static/quiz/` — клиент (HTML/CSS/JS/Vue)
